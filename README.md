# Memory Game

Игра на поиск пар: открывайте карточки и находите все 8 пар за минимальное число ходов.

- 16 карточек (8 пар), счётчики ходов и найденных пар
- таблица лидеров — топ-10 результатов, хранится в `localStorage`
- модальные окна победы и таблицы лидеров

## Запуск

Приложение использует ES-модули, поэтому открывать его нужно через локальный сервер:

```bash
npx serve .
# или
python3 -m http.server
```

В VS Code удобнее всего расширение **Live Server**: установите его, кликните правой кнопкой по `index.html` и выберите «Open with Live Server».

Затем откройте в браузере адрес, который выведет сервер (например, `http://localhost:3000`).

## Стек

Чистые HTML/CSS/JS, без библиотек и фреймворков. Вся разметка создаётся через `document.createElement`.
